# 26. Jazyk JavaScript

---

### 1. Skriptování na straně klienta

JavaScript je primárním jazykem pro **skriptování na straně klienta** (client-side scripting).

- **Princip:** Kód se stahuje spolu s HTML a CSS a vykonává ho až webový prohlížeč uživatele.
- **Význam:** Umožňuje vytvářet interaktivní prvky (validace formulářů před odesláním, animace, galerie, změny obsahu bez reloadu).
- **Výhoda:** Snižuje zátěž serveru a poskytuje uživateli okamžitou odezvu.

---

### 2. Připojení k HTML a základní syntaxe

JavaScript lze do webové stránky vložit několika způsoby:

- **Externí soubor:** Nejlepší praxe. Kód je v souboru `.js` a připojuje se v HTML pomocí `<script src="skript.js"></script>`.
- **Vnitřní skript:** Kód přímo v HTML mezi značkami `<script> ... </script>`.
- **Inline zápis:** Kód přímo v atributu HTML prvku (např. `onclick="..."`), což se dnes pro větší projekty nedoporučuje.

Základní syntaxe:

- **Proměnné:** Deklarují se pomocí `let` (měnitelná) nebo `const` (konstanta).
- **Funkce:** Bloky kódu, které se spustí při zavolání (např. `function pozdrav() { ... }`).

---

### 3. DOM (Document Object Model)

Aby mohl JavaScript měnit stránku, musí k ní mít přístup. To zajišťuje **DOM**.

- **Význam:** DOM je stromová struktura, kde každý HTML prvek je objektem, se kterým může JS pracovat.
- Výběr elementu:
    - `document.getElementById('id-prvku')` – výběr podle unikátního ID.
    - `document.querySelector('.trida')` – moderní způsob výběru pomocí CSS selektorů.

---

### 4. Události a reakce (Events)

Události jsou akce uživatele (nebo prohlížeče), na které JavaScript reaguje.

- **Příklady:** `click` (kliknutí), `submit` (odeslání formuláře), `mouseover` (najetí myší), `load` (načtení stránky).
- Způsoby ošetření:
    - **Atribut v HTML:** `<button onclick="funkce()">`.
    - **Metoda `addEventListener`:** Moderní a čistý způsob v JS souboru:
        
        `tlacitko.addEventListener('click', mojeFunkce);`.
        

---

### 5. Manipulace s obsahem a vzhledem

Po zachycení události JavaScript obvykle něco na stránce změní:

- **Manipulace s HTML:** Změna textu nebo vnořeného HTML pomocí vlastnosti `innerHTML` nebo `textContent`.
- **Manipulace s CSS:** Změna stylu pomocí vlastnosti `style` (např. `element.style.display = 'none';`) nebo přidáváním/odebíráním CSS tříd přes `classList`.

---

### Praktický příklad: Interaktivní tlačítko

U zkoušky se často žádá jednoduchý příklad: "Napište skript, který po kliknutí na tlačítko změní text v odstavci."

JavaScript

```jsx
// 1. Výběr prvků z DOM
const tlacitko = document.getElementById('mojeTlacitko');
const text = document.getElementById('zprava');

// 2. Definice reakce na událost
tlacitko.addEventListener('click', function() {
    // 3. Manipulace s obsahem a stylem
    text.innerHTML = "Bylo kliknuto!";
    text.style.color = "red";
    text.style.fontWeight = "bold";
});
```

---

### 💡 Tahák pro maturanta (klíčové body):

- 
    
    **JavaScript** běží u klienta (v prohlížeči), ne na serveru.
    
- 
    
    **DOM** je hierarchie prvků stránky, kterou JS používá jako "mapu".
    
- 
    
    **`addEventListener`** je preferovaný způsob, jak naslouchat akcím uživatele.
    
- Proměnné: **`const`** pro věci, co se nemění, **`let`** pro ty, co ano.
- 
    
    **Manipulace:** JS může měnit jak **obsah** (`innerHTML`), tak **vzhled** (`style`) prvků v reálném čase.
