# 17. Jazyk CSS

---

### 1. Význam a syntaxe CSS

Před samotnými selektory je dobré zmínit, že **CSS (Cascading Style Sheets)** slouží k oddělení obsahu (HTML) od vizuálního vzhledu.

- **Základní pravidlo:** Skládá se ze **selektoru** a **bloku deklarací** (složené závorky).
- **Deklarace:** Obsahuje **vlastnost** a **hodnotu** (např. `color: red;`).

---

### 2. Základní typy selektorů

U maturity je důležité ukázat, že umíš vybrat prvek různými způsoby podle potřeby:

- **Typový selektor (značka):** Cílí na všechny prvky daného typu (např. všechny odstavce).
    - *Příklad:* `p { color: blue; }`
- **Třída (class):** Používá se pro skupinu prvků, které mají mít stejný styl. V CSS se zapisuje s tečkou. Jeden prvek může mít více tříd.
    - *Příklad:* `.hlavni-text { font-size: 18px; }`
- **Identifikátor (ID):** Používá se pro jeden unikátní prvek na stránce. V CSS se zapisuje s hashtagem.
    - *Příklad:* `#hlavni-menu { background: grey; }`

---

### 3. Vztahy mezi prvky (Kombinátory)

Selektory umožňují vybírat prvky na základě jejich pozice v kódu:

- **Potomek (mezera):** Vybere všechny prvky uvnitř jiného prvku (i hluboko zanořené).
    - *Příklad:* `nav a { text-decoration: none; }` (vybere všechny odkazy v navigaci)
- **Přímý potomek (`>`):** Vybere pouze ty prvky, které jsou v hierarchii přímo pod rodičem.
- **Následník (`+` nebo `~`):** Vybere prvek, který následuje po jiném prvku na stejné úrovni.

---

### 4. Pseudotřídy a atributové selektory

Tyto selektory reagují na stav prvku nebo jeho vlastnosti:

- **Pseudotřídy:** Definují styl prvku v určitém stavu.
    - `:hover` – když uživatel na prvek najede myší.
    - `:focus` – když je prvek aktivní (např. kliknutí do pole formuláře).
    - `:nth-child(n)` – vybere n-tý prvek v pořadí (např. sudé řádky tabulky).
- **Atributové selektory:** Cílí na prvky podle jejich HTML atributů (např. typ inputu).
    - *Příklad:* `input[type="text"] { border: 1px solid black; }`

---

### Praktický příklad: Kombinace selektorů

CSS

```css
/* 1. Typový selektor pro nadpis */
h1 {
    font-family: Arial, sans-serif;
}

/* 2. Třída pro zvýrazněné prvky */
.dulezite {
    color: red;
    font-weight: bold;
}

/* 3. Selektor potomka a pseudotřída */
/* Změní barvu odkazu v navigaci pouze při najetí myší */
nav a:hover {
    color: orange;
}

/* 4. Atributový selektor pro tlačítka */
button[disabled] {
    opacity: 0.5;
    cursor: not-allowed;
}
```

---

### 💡 Tahák pro maturanta (klíčové body):

- **Selektor** určuje, na co se styl aplikuje, **deklarace** (vlastnost: hodnota) určuje co se změní.
- **Tečka (`.`)** je pro třídy (může jich být víc), **mřížka (`#`)** pro ID (musí být unikátní).
- **Mezera** mezi selektory znamená jakýkoliv potomek, **`>`** znamená pouze přímý potomek.
- **Pseudotřídy** (jako `:hover` nebo `:active`) umožňují dynamické změny bez JavaScriptu.
- **Priorita (Specificita):** ID má větší váhu než třída, třída má větší váhu než značka.
