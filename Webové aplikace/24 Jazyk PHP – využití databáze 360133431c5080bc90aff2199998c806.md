# 24. Jazyk PHP – využití databáze

---

### 1. Princip využití databáze ve webové aplikaci

Většina moderních webů potřebuje trvale ukládat data (uživatele, články, objednávky). K tomu slouží **databázový systém** (nejčastěji MySQL nebo MariaDB).

- **Oddělení dat:** PHP skript obsahuje logiku, zatímco databáze obsahuje surová data v tabulkách.
- **SQL (Structured Query Language):** Jazyk, kterým PHP komunikuje s databází (příkazy jako `SELECT`, `INSERT`, `UPDATE`, `DELETE`).

---

### 2. Rozšíření v PHP (MySQLi vs. PDO)

Pro práci s databází nabízí PHP dvě hlavní cesty:

1. **MySQLi (MySQL Improved):**
    - Určeno výhradně pro databáze MySQL.
    - Umožňuje **procedurální** (klasické funkce) i **objektový** přístup.
2. **PDO (PHP Data Objects):**
    - Univerzální rozhraní – stejný kód lze s minimálními změnami použít pro MySQL, PostgreSQL, SQLite a další.
    - Je čistě **objektové**.

---

### 3. Práce s MySQLi (Procedurální přístup)

Toto je nejčastější způsob u zkoušek díky své přímočarosti. Typický cyklus práce s DB obsahuje tyto kroky:

1. **Připojení:** Pomocí `mysqli_connect($server, $uzivatel, $heslo, $databaze)`.
2. **Nastavení kódování:** `mysqli_set_charset($spojeni, "utf8mb4")` pro správné zobrazení češtiny.
3. **Provedení dotazu:** `mysqli_query($spojeni, $sql)`.
4. **Zpracování výsledků:** Načtení dat do pole (např. přes `mysqli_fetch_assoc`).
5. **Uzavření spojení:** `mysqli_close($spojeni)`.

---

### 4. Objektový přístup a PDO

Modernější způsob vývoje využívá třídy a objekty:

- **MySQLi (objektově):** Vytvoří se instance třídy `mysqli` a metody se volají pomocí operátoru `->` (např. `$db->query()`).
- **PDO:** Vytváří se objekt `new PDO()`. Výhodou je vyšší bezpečnost (snadnější použití tzv. "prepared statements" proti SQL injection).

---

### Praktický příklad: Výpis dat z databáze (MySQLi)

U maturity se často vyžaduje ukázka kódu pro vypsání tabulky.

PHP

```php
<?php
// 1. Parametry připojení
$spojeni = mysqli_connect("localhost", "root", "", "moje_databaze");

// 2. Kontrola připojení a nastavení češtiny
if ($spojeni) {
    mysqli_set_charset($spojeni, "utf8mb4");

    // 3. SQL dotaz
    $sql = "SELECT id, jmeno FROM uzivatele";
    $vysledek = mysqli_query($spojeni, $sql);

    // 4. Zpracování výsledků cyklem
    while ($radek = mysqli_fetch_assoc($vysledek)) {
        echo "ID: " . $radek['id'] . " - Jméno: " . $radek['jmeno'] . "<br>";
    }

    // 5. Uzavření
    mysqli_close($spojeni);
}
?>
```

---

### 💡 Tahák pro maturanta (klíčové body):

- **Princip:** PHP posílá SQL dotazy, databáze vrací data.
- **MySQLi:** Specifické pro MySQL, podporuje funkce (procedurální) i objekty.
- **PDO:** Univerzální pro více typů databází, vždy objektové.
- **Kódování:** Nezapomeň zmínit `mysqli_set_charset`, jinak nebude fungovat čeština.
- **Zpracování:** Výsledek z DB je obvykle pole, které procházíme cyklem `while`.
