# 23. Java a databáze – DDL, DML

---

### 1. Nastavení projektu a JDBC

Aby Java mohla komunikovat s databází (např. MySQL), potřebuje k tomu příslušný **ovladač** (Driver).

- **Modulární systém:** V moderních verzích Javy je nutné do souboru `module-info.java` přidat řádek `requires java.sql;`, aby projekt mohl využívat databázové třídy.
- **JDBC URL:** Adresa, která specifikuje, kam se připojujeme. Má formát: `jdbc:mysql://localhost/nazev_databaze`.
- **Přihlašovací údaje:** Obvykle uživatelské jméno (např. `"root"`) a heslo.

### 2. Připojení k databázi

K navázání spojení používáme třídu `DriverManager` a rozhraní `Connection`.

- **Navázání spojení:** `Connection spojeni = DriverManager.getConnection(url, uzivatel, heslo);`.
- **Ukončení spojení:** Po dokončení práce je nutné spojení uzavřít pomocí `spojeni.close();`, aby se uvolnily zdroje.

### 3. DDL – Data Definition Language

DDL (Jazyk pro definici dat) slouží k vytváření a úpravám **struktury** databáze (tabulky, indexy).

- **Základní příkazy SQL:** `CREATE TABLE` (vytvoření), `DROP TABLE` (smazání tabulky), `ALTER TABLE` (změna struktury).
- **Provedení v Javě:** K vykonání DDL příkazů v Javě používáme metodu `executeUpdate()`, která v tomto případě nevrací počet ovlivněných řádků, ale slouží k provedení změny schématu.

### 4. DML – Data Manipulation Language

DML (Jazyk pro manipulaci s daty) slouží k práci se samotnými **záznamy** v tabulkách.

- **Základní příkazy SQL:**
    - `INSERT INTO`: vložení nového záznamu.
    - `UPDATE`: úprava stávajících dat.
    - `DELETE`: smazání záznamu.
- **PreparedStatement:** Pro bezpečné a efektivní provádění DML příkazů používáme rozhraní `PreparedStatement`.
    - Umožňuje používat parametry (zástupné znaky `?`), čímž chrání před útoky typu SQL Injection.
    - Metody `setXxx(index, hodnota)` nastavují hodnoty pro tyto parametry (např. `setInt`, `setString`).
    - Metoda `executeUpdate()` provede dotaz a vrátí `int` – počet řádků, které byly v databázi změněny.

---

### Praktický příklad: Vložení dat do tabulky

Java

```java
import java.sql.*;

public class DatabazeDML {
    public static void main(String[] args) {
        String url = "jdbc:mysql://localhost/moje_db";
        String user = "root";
        String pass = "";

        // Použití try-with-resources pro automatické zavření
        try (Connection conn = DriverManager.getConnection(url, user, pass)) {
            String sql = "INSERT INTO studenti (jmeno, vek) VALUES (?, ?)";
            
            PreparedStatement ps = conn.prepareStatement(sql);
            ps.setString(1, "Karel"); // Nastaví první '?' na "Karel" 
            ps.setInt(2, 20);         // Nastaví druhý '?' na 20 
            
            int ovlivneno = ps.executeUpdate(); // Provede INSERT 
            System.out.println("Bylo vloženo řádků: " + ovlivneno);
            
            ps.close(); // Uzavření příkazu [cite: 20, 21]
        } catch (SQLException e) {
            e.printStackTrace();
        }
    }
}
```

### 💡 Tahák pro maturanta (klíčové body):

- **JDBC** je rozhraní pro komunikaci Javy s různými databázemi.
- **`Connection`** reprezentuje otevřené spojení.
- **DDL** mění tabulky (`CREATE`, `DROP`), **DML** mění data (`INSERT`, `UPDATE`, `DELETE`).
- **`PreparedStatement`** je bezpečnější než obyčejný `Statement`.
- **`executeUpdate()`** se používá pro vše, co **nemění** data na výstupu (vrací jen počet změněných řádků).
- **`requires java.sql;`** musí být v `module-info.java`.
