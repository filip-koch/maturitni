# 12. Jednorozměrné pole (C)

---

### 1. Definice a charakteristika pole

Jednorozměrné pole (vektor) je datová struktura, která sdružuje pevný počet prvků **stejného datového typu**.

- **Souvislost v paměti:** Prvky pole jsou v operační paměti uloženy bezprostředně za sebou.
- **Indexování:** K jednotlivým prvkům přistupujeme pomocí indexu v hranatých závorkách `[]`. V jazyce C se indexuje vždy **od nuly** (první prvek má index 0, poslední prvek má index `velikost - 1`).
- **Meze pole:** Jazyk C **nekontroluje**, zda přistupujete k platnému indexu. Pokud sáhnete mimo pole, program může spadnout nebo přepsat jiná data v paměti.

### 2. Statické pole

Velikost pole je určena pevně v kódu a nelze ji během běhu programu měnit.

- **Alokace:** Probíhá na **zásobníku (stack)**.
- **Deklarace:** `typ jmeno[velikost];` (např. `int cisla[10];`).
- **Inicializace:** `int pole[] = {1, 2, 3};` – překladač si velikost dopočítá sám.

### 3. Dynamické pole

Velikost pole můžeme určit až během běhu programu (např. podle vstupu od uživatele).

- **Alokace:** Probíhá v **haldě (heap)** pomocí funkce `malloc()`.
- **Práce s ním:** S dynamickým polem pracujeme pomocí **pointeru**.
- **Uvolnění:** Po skončení práce musíme paměť ručně uvolnit funkcí `free()`, jinak dojde k úniku paměti.

### 4. Pole jako parametr funkce

Při předávání pole do funkce dochází k tzv. **degradaci pole na pointer**.

- Funkce nedostane kopii celého pole, ale pouze **adresu jeho prvního prvku**.
- **Důležité:** Jelikož pole "zapomene" svou velikost, musíme ji funkci předat jako **druhý parametr**.

### 5. Třídící algoritmy (např. Bubble Sort)

U maturity se často vyžaduje znalost jednoduchého algoritmu pro seřazení prvků v poli.

- **Bubble Sort (Bublinkové řazení):** Opakovaně prochází pole a porovnává sousední prvky. Pokud jsou ve špatném pořadí, prohodí je. Větší prvky tak „probublávají“ na konec pole.

---

### Praktický příklad: Práce se statickým polem a výpočet průměru

```c
#include <stdio.h>

int main() {
    int znamky[5] = {1, 2, 4, 1, 3}; // Statické pole
    int suma = 0;

    for (int i = 0; i < 5; i++) {
        suma += znamky[i]; // Přístup k prvkům pomocí indexu
    }

    double prumer = (double)suma / 5;
    printf("Prumerna znamka: %.2f", prumer);

    return 0;
}
```

---

### 💡 Tahák pro maturanta (klíčové body):

- **Indexy:** Začínají od 0, končí u $n-1$.
- **Paměť:** Pole je jeden souvislý blok dat.
- **Statické vs. Dynamické:** Statické má pevnou velikost, dynamické (`malloc`) se může přizpůsobit.
- **Předávání funkci:** Pole se předává odkazem (pointerem), proto funkce může měnit jeho obsah.
- **Třídění:** Bubble Sort je nejjednodušší na naprogramování, ale nejpomalejší pro velká data.
