# 3. Řídící struktury – cykly

---

### 1. Definice a význam cyklů

Cyklus (iterace) je řídící struktura, která umožňuje opakované provádění určitého bloku příkazů (těla cyklu) v závislosti na splnění stanovené podmínky. Jedno provedení těla cyklu se nazývá **iterace**.

### 2. Typy cyklů a jejich charakteristika

V jazycích C a Java rozlišujeme tři základní typy cyklů:

### A) Cyklus s podmínkou na začátku (`while`)

- **Princip:** Nejdříve se vyhodnotí podmínka. Pokud platí, provede se tělo cyklu a program se vrátí k podmínce.
- **Vlastnost:** Pokud podmínka neplatí hned na začátku, tělo cyklu se **neprovede ani jednou**.
- **Použití:** Když dopředu nevíme, kolikrát se bude opakovat, a je možné, že se neprovede vůbec.

### B) Cyklus s podmínkou na konci (`do-while`)

- **Princip:** Nejdříve se provede tělo cyklu a až poté se testuje podmínka.
- **Vlastnost:** Tělo cyklu se provede **vždy alespoň jednou**.
- **Použití:** V situacích, kdy potřebujeme akci provést (např. načíst vstup) a až pak kontrolovat, zda v ní pokračovat.

### C) Cyklus s řídící proměnnou (`for`)

- **Princip:** Obsahuje tři části v záhlaví: inicializace řídící proměnné, podmínka a inkrementace (změna hodnoty).
- **Vlastnost:** Je to v podstatě přehlednější zápis cyklu `while`.
- **Použití:** Když je předem **znám počet opakování** (např. „udělej to 10x“ nebo „projdi pole od 0 do 9“).

### 3. Grafický zápis (Vývojové diagramy)

V grafickém zápisu používáme pro cykly kombinaci rozhodovacího bloku (kosočtverec) a zpětné vazby.

- **While:** Kosočtverec je nad tělem cyklu.
- **Do-while:** Kosočtverec je pod tělem cyklu.
- **Značka pro `for`:** Někdy se používá speciální blok (šestihran) s popisem `start, stop, krok`.

### 4. Příkazy pro skoky v cyklech

Umožňují programátorovi jemněji ovládat běh cyklu:

1. **`break`:** Okamžitě ukončí celý cyklus a program pokračuje prvním příkazem za cyklem.
2. **`continue`:** Ukončí pouze **aktuální iteraci** (přeskočí zbytek těla) a skočí rovnou na další vyhodnocení podmínky nebo iterační výraz.

---

### Praktický příklad: Výpočet součtu čísel (v C i Javě)

Následující kód demonstruje cyklus `for` pro sečtení čísel od 1 do 10.

C

```c
#include <stdio.h>

int main() {
    int suma = 0;

    // for(inicializace; podmínka; změna)
    for (int i = 1; i <= 10; i++) {
        suma += i; // Přičte hodnotu 'i' k sumě
    }

    printf("Soucet cisel 1-10 je: %d", suma); // Vypíše 55
    return 0;
}
```

---

### 💡 Tahák pro maturanta (klíčové body):

- **While:** Podmínka na začátku, nemusí proběhnout ani jednou.
- **Do-while:** Podmínka na konci, proběhne vždy aspoň jednou.
- **For:** Tři části – inicializace, podmínka, krok.
- **Break vs. Continue:** `break` = útěk z cyklu ven, `continue` = skok na další kolo (iteraci).
- **Nekonečný cyklus:** Vznikne, pokud podmínka nikdy nenabude hodnoty `false` (nula).
- **Složené tělo:** Pokud má cyklus více příkazů, musí být v závorkách `{ }`.
