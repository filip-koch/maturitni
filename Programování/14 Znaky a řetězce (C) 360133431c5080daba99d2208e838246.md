# 14. Znaky a řetězce (C)

---

### 1. Znaková proměnná (`char`)

Základním stavebním kamenem textu je typ `char`.

- **Charakteristika:** Slouží k uložení jednoho znaku (písmeno, číslice, symbol). V paměti zabírá **1 bajt**.
- **Kódování:** Interně se znak ukládá jako celé číslo (0–255) podle **ASCII tabulky**. Např. znak 'A' má hodnotu 65.
- **Deklarace:** Znaky píšeme vždy do **jednoduchých apostrofů**.
    - `char pismeno = 'A';`

### 2. Řetězec v jazyce C

Řetězec (string) je v C definován jako **jednorozměrné pole typu `char`**.

- **Ukončovací znak (`\0`):** Toto je nejdůležitější informace u maturity. Každý řetězec musí být v paměti zakončen tzv. **nulovým znakem** (`NULL` nebo `'\0'`). Tento znak říká funkcím, kde text končí.
- **Velikost v paměti:** Pole pro řetězec musí být vždy o 1 prvek delší, než je počet viditelných znaků (kvůli `\0`).
- **Zápis:** Řetězce píšeme do **uvozovek**.
    - `char text[] = "Ahoj";` // V paměti zabere 5 bajtů: 'A', 'h', 'o', 'j', '\0'.

### 3. Základy práce s řetězci

- **Načítání:**
    - `scanf("%s", pole);` – načte text po první mezeru.
    - `fgets(pole, velikost, stdin);` – bezpečnější způsob, načte celý řádek i s mezerami.
- **Výpis:**
    - `printf("%s", pole);` nebo `puts(pole);`.

### 4. Funkce pro práci s řetězci (`string.h`)

Pro manipulaci s textem musíme vložit knihovnu `#include <string.h>`. Nejdůležitější funkce jsou:

1. **`strlen(s)`**: Vrátí délku řetězce (počet znaků bez `\0`).
2. **`strcpy(cíl, zdroj)`**: Zkopíruje obsah jednoho řetězce do druhého. (Pozor: `=` u polí nefunguje!).
3. **`strcat(cíl, zdroj)`**: Připojí (přilepí) druhý řetězec na konec prvního.
4. **`strcmp(s1, s2)`**: Porovná dva řetězce. Vrací 0, pokud jsou stejné.
5. **`strchr(s, c)` / `strstr(s1, s2)`**: Hledání znaku nebo podřetězce v textu.

### 5. Parametry funkce `main()`

U této otázky se často zapomíná na to, jak program přijímá textové parametry z příkazové řádky.

- `int main(int argc, char *argv[])`
    - **`argc`**: Počet argumentů (včetně názvu programu).
    - **`argv`**: Pole řetězců (pointerů na char), které obsahují jednotlivá slova příkazu.

---

### Praktický příklad: Bezpečné kopírování a zjištění délky

```c
#include <stdio.h>
#include <string.h>

int main() {
    char zdroj[] = "Maturita";
    char cil[20];

    // Kopírování textu
    strcpy(cil, zdroj); 

    // Změna textu
    strcat(cil, " 2026");

    printf("Text: %s\n", cil);
    printf("Delka: %d znaku\n", (int)strlen(cil)); // Vypíše 13

    return 0;
}
```

---

### 💡 Tahák pro maturanta (klíčové body):

- **`char`** je v podstatě malé celé číslo (ASCII).
- **Řetězec** není objekt, je to **pole** zakončené nulou `\0`.
- **Nula na konci** je kritická – bez ní funkce pro výpis „přejedou“ konec pole a vypíší smetí z paměti.
- **Operátor `=`** nelze použít pro kopírování řetězců (kopírovali byste jen adresu), musíte použít `strcpy()`.
- **`strcmp()`** vrací nulu, pokud jsou řetězce identické (to je častý chyták).
