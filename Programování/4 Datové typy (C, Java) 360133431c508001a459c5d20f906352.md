# 4. Datové typy (C, Java)

---

### 1. Definice datového typu

Datový typ určuje:

1. **Množinu hodnot**, kterých může proměnná nabývat (např. celá čísla, znaky).
2. **Množinu operací**, které lze s proměnnou provádět (např. sčítání, spojování řetězců).
3. **Velikost v paměti**, kterou proměnná obsadí (počet bajtů).

### 2. Rozdělení datových typů

U maturity je dobré rozdělit typy podle těchto kritérií:

- **Podle složitosti:**
    - **Jednoduché (homogenní):** Obsahují jedinou hodnotu (např. `int`, `char`).
    - **Strukturované (heterogenní):** Skládají se z více prvků (např. pole, struktura v C, třída v Javě).
- **Podle určení v jazyce:**
    - **Standardní (vestavěné):** Jsou součástí jazyka.
    - **Uživatelské:** Definované programátorem (např. pomocí `typedef` nebo `class`).

### 3. Srovnání C a Java

Toto je nejdůležitější část pro pochopení rozdílů mezi těmito jazyky.

| **Vlastnost** | **Jazyk C** | **Jazyk Java** |
| --- | --- | --- |
| **Logický typ** | Neexistuje (používá se 0 pro `false`, nenulová pro `true`). | Typ `boolean` (hodnoty `true` / `false`). |
| **Velikost typů** | Závislá na architektuře (např. `int` může mít 2 i 4 bajty). | Fixní velikost nezávislá na platformě (např. `int` má vždy 4 bajty). |
| **Znaky** | `char` (1 bajt, kódování ASCII). | `char` (2 bajty, kódování Unicode/UTF-16). |

### 4. Přehled základních typů

### C a Java (společné základy):

- **Celá čísla:** `int` (standardní), `short` (menší rozsah), `long` (větší rozsah).
- **Reálná čísla (desetinná):** `float` (jednoduchá přesnost), `double` (dvojitá přesnost).
- **Znak:** `char` (v C slouží i jako nejmenší celočíselný typ).

### Modifikátory v jazyce C:

V C můžeme měnit vlastnosti typů pomocí klíčových slov:

- **`unsigned`:** Typ bude pouze nezáporný (posouvá rozsah do kladných čísel, např. 0 až 65535 místo -32768 až 32767).
- **`signed`:** Výchozí stav, typ může být kladný i záporný.

### 5. Definování nových typů (`typedef` v C)

Klíčové slovo `typedef` se používá k vytvoření „přezdívky“ (aliasu) pro existující datový typ. Zvyšuje to čitelnost kódu.

- **Syntaxe:** `typedef <existující_typ> <nový_název>;`.
- **Příklad:** `typedef unsigned char BYTE;` – od této chvíle můžeme místo `unsigned char` psát prostě `BYTE`.

---

### Praktická ukázka deklarace

**V jazyce C:**

```c
int vek = 20;             // Celé číslo
double cena = 199.90;     // Reálné číslo
char pismeno = 'A';       // Znak (v C uvozen apostrofy)
unsigned int pocet = 100; // Pouze kladné číslo
```

**V jazyce Java:**

```java
int vek = 20;
double cena = 199.90;
char pismeno = 'A';
boolean jeHotovo = true;  // Specifické pro Javu
```

---

### 💡 Tahák pro maturanta (klíčové body):

- **Datový typ** = rozsah hodnot + povolené operace + velikost v paměti.
- **Java je přísnější:** Typ `boolean` je samostatný, nelze ho zaměnit za číslo jako v C.
- **C je flexibilnější:** `char` v C je v podstatě malé číslo (0–255), se kterým lze běžně počítat.
- **Plovoucí řádová čárka:** Pro finance raději `double` než `float` (vyšší přesnost).
- **Typedef:** Používej pro zkrácení dlouhých názvů (např. u struktur).
