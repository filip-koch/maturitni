# 15. Soubory (C)

---

### 1. Účel a rozdělení souborů

Soubory slouží k ukládání dat mimo operační paměť na vnější paměťová média. V jazyce C je dělíme na dvě základní skupiny:

- **Textové soubory:**
    - Data jsou uložena jako posloupnost znaků (ASCII).
    - Jsou čitelné pro člověka v běžných editorech (např. Poznámkový blok).
    - Obsahují speciální znaky jako konec řádku (`\n`) nebo konec souboru (`EOF`).
- **Binární soubory:**
    - Data jsou přesným obrazem paměti počítače (posloupnost bajtů).
    - Nejsou čitelná pro člověka, ale jsou úspornější na místo a rychlejší na zpracování.
    - Ukládají se do nich přímo struktury, pole nebo čísla v jejich vnitřní reprezentaci.

### 2. Postup práce se souborem

Práce se souborem v C probíhá vždy v těchto krocích:

1. **Definice pointeru:** Musíme vytvořit ukazatel na strukturu `FILE`.
    - `FILE *fw;`
2. **Otevření souboru (`fopen`):** Funkce propojí pointer s konkrétním souborem na disku.
    - `fw = fopen("data.txt", "r");`
3. **Kontrola otevření:** Vždy musíme ověřit, zda se soubor skutečně otevřel. Pokud ne (např. soubor neexistuje), funkce vrátí hodnotu `NULL`.
4. **Zpracování dat:** Čtení ze souboru nebo zápis do něj.
5. **Uzavření souboru (`fclose`):** Uvolní systémové prostředky a zajistí, že se všechna data z vyrovnávací paměti skutečně zapíší na disk.

### 3. Režimy otevření souboru

Při otevírání určujeme, co se souborem hodláme dělat:

- **`"r"` (Read):** Čtení. Soubor musí existovat, jinak se otevření nezdaří.
- **`"w"` (Write):** Zápis. Pokud soubor existuje, jeho obsah se smaže. Pokud neexistuje, vytvoří se nový.
- **`"a"` (Append):** Přidávání. Data se připisují na konec existujícího souboru.

### 4. Standardní funkce pro vstup a výstup

Pro práci s daty používáme různé funkce podle toho, jaký typ dat zpracováváme:

| **Typ dat** | **Čtení** | **Zápis** |
| --- | --- | --- |
| **Znak** | `fgetc(stream)` | `fputc(znak, stream)` |
| **Řetězec (řádek)** | `fgets(pole, max, stream)` | `fputs(text, stream)` |
| **Formátovaný text** | `fscanf(stream, "...", ...)` | `fprintf(stream, "...", ...)` |
| **Binární data** | `fread(...)` | `fwrite(...)` |

---

### Praktický příklad: Zápis a čtení textového souboru

```c
#include <stdio.h>

int main() {
    FILE *f;
    int cislo = 42;

    // 1. Zápis do souboru
    f = fopen("vystup.txt", "w");
    if (f != NULL) { // Kontrola otevření
        fprintf(f, "Vysledek je: %d", cislo);
        fclose(f); // Vždy zavřít!
    }

    // 2. Čtení ze souboru
    char radek[50];
    f = fopen("vystup.txt", "r");
    if (f != NULL) {
        if (fgets(radek, 50, f) != NULL) {
            printf("Nacteno: %s", radek);
        }
        fclose(f);
    }

    return 0;
}
```

---

### 💡 Tahák pro maturanta (klíčové body):

- **`FILE *`** je datový typ (pointer) pro práci se soubory.
- **`fopen`** vyžaduje název a režim ("r", "w", "a").
- **Vždy kontroluj `NULL`** – bez toho program spadne, když soubor nepůjde otevřít.
- **`fclose`** je nutnost, jinak hrozí ztráta dat nebo poškození souboru.
- **`EOF`** (End Of File) je konstanta, která značí, že jsme na konci souboru při čtení po znacích.
