# 20. Soubory (Java)

---

### 1. Třída `File` – Práce s metadaty

Třída `File` neslouží k samotnému čtení obsahu souboru, ale k manipulaci se souborem jako takovým na disku.

- **Účel:** Zjišťování informací o souborech a adresářích (existuje soubor? je to složka? jak je velký?).
- **Základní metody:**
    - `exists()`: Vrací `true`, pokud soubor existuje.
    - `isFile()` / `isDirectory()`: Rozliší mezi souborem a složkou.
    - `createNewFile()`: Vytvoří nový prázdný soubor.
    - `delete()`: Smaže soubor nebo prázdný adresář.
    - `length()`: Vrátí velikost souboru v bajtech.

### 2. Koncept proudů (Streams)

Java používá pro vstup a výstup (I/O) koncept proudů. Proud si představ jako "potrubí", kterým tečou data od zdroje (soubor) k cíli (program) a naopak.

- **Vstupní proudy (Input):** Pro čtení dat.
- **Výstupní proudy (Output):** Pro zápis dat.

### 3. Znakové proudy (Textové soubory)

Používají se pro práci s textem. Java automaticky řeší kódování znaků (Unicode). Základem jsou abstraktní třídy **`Reader`** a **`Writer`**.

- **`FileReader` / `FileWriter`:** Základní třídy pro čtení/zápis znaků ze souboru.
- **`BufferedReader` / `BufferedWriter`:** Používají vyrovnávací paměť (buffer). Jsou mnohem efektivnější, protože nečtou z disku po jednom znaku, ale po celých blocích.
    - Metoda `readLine()` u `BufferedReader` je nejpoužívanější pro čtení textu po celých řádcích.
    - Metoda `newLine()` u `BufferedWriter` zajistí správný konec řádku podle operačního systému.

### 4. Binární proudy (Obecná data)

Používají se pro soubory, které nejsou čitelné jako text (obrázky, .exe soubory, šifrovaná data). Pracují s jednotlivými bajty (8 bitů). Základem jsou třídy **`InputStream`** a **`OutputStream`**.

- **`FileInputStream` / `FileOutputStream`:** Základní čtení a zápis bajtů.
- **`BufferedInputStream` / `BufferedOutputStream`:** Opět přidávají vyrovnávací paměť pro zrychlení práce.

### 5. Výjimky a uzavírání souborů

Práce se soubory v Javě vyžaduje povinné ošetření výjimek (**`try-catch`** blok), protože může dojít k chybám (soubor nenalezen, disk je plný).

- **Důležité:** Každý proud se musí po dokončení práce uzavřít metodou **`.close()`**, aby se uvolnily systémové prostředky.

---

### Praktický příklad: Čtení textového souboru po řádcích

Java

```java
import java.io.*;

public class CteniSouboru {
    public static void main(String[] args) {
        // Použití try-with-resources (automaticky zavře soubor)
        try (BufferedReader br = new BufferedReader(new FileReader("test.txt"))) {
            String radek;
            while ((radek = br.readLine()) != null) { // Čte, dokud není konec
                System.out.println(radek);
            }
        } catch (IOException e) {
            System.out.println("Chyba při čtení souboru: " + e.getMessage());
        }
    }
}
```

---

### 💡 Tahák pro maturanta (klíčové body):

- **Třída `File`** = metadata (velikost, název, existence), nikoliv obsah.
- **Znakové proudy (`Reader`/`Writer`)** = textové soubory.
- **Binární proudy (`InputStream`/`OutputStream`)** = všechno ostatní (bajty).
- **Bufferování** = kritické pro rychlost; vždy balit `FileReader` do `BufferedReader`.
- **`readLine()`** vrací `null`, pokud narazí na konec souboru.
- **Zavírání:** Vždy použij `.close()` nebo konstrukci *try-with-resources*.
