# 13. Vícerozměrné pole (C)

---

### 1. Charakteristika vícerozměrného pole

Vícerozměrné pole je pole, jehož prvky jsou opět pole. Nejčastěji se setkáváme s **dvourozměrným polem** (maticí).

- **Logická představa:** Tabulka s $R$ řádky a $S$ sloupci.
- **Indexování:** K prvkům přistupujeme pomocí dvou indexů v samostatných závorkách: `matice[radek][sloupec]`. Indexuje se opět od **0**.
- **Uložení v paměti:** I když si pole představujeme jako tabulku, v paměti (RAM) je uloženo jako **jeden souvislý lineární blok** dat, kde jdou prvky za sebou po řádcích (tzv. *row-major order*).

### 2. Statické vícerozměrné pole

Velikost obou rozměrů musí být známa již při psaní kódu (před překladem).

- **Deklarace:** `int matice[3][4];` (matice se 3 řádky a 4 sloupci).
- **Inicializace:** `int m[2][2] = { {1, 2}, {3, 4} };`.
- **Vlastnosti:** Alokuje se na **zásobníku (stack)**, má pevnou velikost, kterou nelze měnit.

### 3. Dynamické vícerozměrné pole

Používáme ho, když počet řádků nebo sloupců zjistíme až za běhu programu. Existuje více způsobů realizace, u maturity se nejčastěji probírá **pole pointerů**.

### Realizace pomocí „pole pointerů“:

1. Vytvoříme pointer na pointer (`int matice`).
2. Alokujeme pole pointerů (každý pointer bude představovat jeden řádek).
3. V cyklu alokujeme pro každý tento pointer samotné pole prvků (sloupce daného řádku).
- **Výhoda:** Řádky nemusí být v paměti hned za sebou a mohou mít dokonce různou délku (tzv. *jagged array*).
- **Důležité:** Paměť musíme uvolňovat v opačném pořadí (nejdříve řádky, pak pole pointerů).

### 4. Pointery a vícerozměrná pole

Zde je potřeba rozlišit tři důležité pojmy:

- **Pointer na pointer (`int p`):** Proměnná, která drží adresu jiného pointeru. Používá se pro dynamické matice.
- **Pole pointerů (`int *p[5]`):** Statické pole pěti prvků, kde každý prvek je pointer na `int`.
- **Pointer na pole (`int (*p)[5]`):** Jeden pointer, který ukazuje na celý blok (v tomto případě na pole pěti celých čísel). Často se používá při předávání matic funkcím.

---

### Praktický příklad: Práce se statickou maticí

```c
#include <stdio.h>

int main() {
    int matice[2][3] = { {1, 2, 3}, {4, 5, 6} };

    // Průchod maticí pomocí vnořených cyklů
    for (int i = 0; i < 2; i++) {       // Prochází řádky
        for (int j = 0; j < 3; j++) {   // Prochází sloupce
            printf("%d ", matice[i][j]);
        }
        printf("\n"); // Nový řádek po vypsání řady
    }

    return 0;
}
```

---

### 💡 Tahák pro maturanta (klíčové body):

- **Logicky:** Tabulka. **Fyzicky v RAM:** Souvislá řada prvků (u statického pole).
- **Indexy:** První je řádek, druhý sloupec. Oba začínají od 0.
- **Statická alokace:** `typ jmeno[R][S]`.
- **Dynamická alokace:** Vyžaduje `malloc` nejdříve pro řádky (pole pointerů) a pak pro sloupce.
- **Předávání funkci:** U statické matice musíte funkci říct počet sloupců (např. `void fce(int m[][5])`), jinak překladač nespočítá adresu prvku.
- **Uvolňování:** Nezapomeň na `free()` pro každý alokovaný řádek u dynamického pole!
