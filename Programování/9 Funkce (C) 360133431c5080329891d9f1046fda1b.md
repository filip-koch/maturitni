# 9. Funkce (C)

---

### 1. Definice a význam funkcí

Funkce je v jazyce C základní programový modul (podprogram), který tvoří uzavřený celek vykonávající konkrétní úkol.

**Hlavní výhody používání funkcí:**

- **Dekompozice:** Rozdělení složitého problému na jednodušší podúlohy.
- **Znovupoužitelnost:** Funkci napíšeme jednou a můžeme ji volat z mnoha míst programu.
- **Přehlednost:** Kód je čitelnější a lépe se v něm hledají chyby.

### 2. Stavba a vlastnosti funkcí

Každá funkce má svou hlavičku a tělo.

**Struktura funkce:**

```c
navratovy_typ jmeno_funkce(parametry) { telo_funkce } 
```

- **Návratový typ:** Určuje, jaký druh dat funkce vrací (např. `int`, `double`, `char`). Pokud funkce nic nevrací, používá se klíčové slovo `void`.
- **Jméno funkce:** Identifikátor, pomocí kterého funkci voláme.
- **Parametry:** Seznam proměnných, které funkci předáváme ke zpracování. Pokud funkce parametry nemá, píšeme prázdné závorky `()` nebo `(void)`.
- **Tělo funkce:** Blok kódu v `{ }`, který se vykoná při volání funkce.
- **Příkaz `return`:** Ukončí činnost funkce a vrátí výslednou hodnotu do místa volání.

### 3. Předávání parametrů

U maturity je kriticky důležité vysvětlit rozdíl v tom, jak se data do funkce „posílají“:

1. **Volání hodnotou (Call by Value):**
    - Funkci se předá **kopie** hodnoty proměnné.
    - Změna proměnné uvnitř funkce **neovlivní** původní proměnnou v místě volání.
2. **Volání odkazem (pomocí pointeru):**
    - Funkci se předá **adresa** proměnné v paměti.
    - Pomocí pointeru může funkce přímo měnit hodnotu původní proměnné.

### 4. Rekurzivní funkce

Rekurze je situace, kdy funkce v rámci svého těla **volá samu sebe**.

- **Podmínka rekurze:** Každá rekurze musí mít **ukončovací podmínku** (tzv. bázický případ). Bez ní by došlo k nekonečnému volání a přetečení zásobníku (Stack Overflow).
- **Využití:** Typicky pro matematické výpočty jako faktoriál nebo Fibonacciho posloupnost.

---

### Praktický příklad: Funkce pro výpočet mocniny

```c
#include <stdio.h>

// Deklarace funkce (prototyp)
int mocnina(int zaklad, int exponent);

int main() {
    int vysledek = mocnina(2, 3); // Volání funkce
    printf("2 na 3 je: %d", vysledek);
    return 0;
}

// Definice funkce
int mocnina(int zaklad, int exponent) {
    int res = 1;
    for (int i = 0; i < exponent; i++) {
        res *= zaklad;
    }
    return res; // Návrat výsledku
}
```

---

### 💡 Tahák pro maturanta (klíčové body):

- **Modularizace:** Program není „špagety kód“, ale skládačka z funkcí.
- **Prototyp:** Dobrým zvykem je deklarovat funkci nad `main()` a definovat ji pod ním (nebo v jiném souboru).
- **Void:** Nezapomeň, že `void` znamená „prázdný“ – buď funkce nic nevrací, nebo nebere parametry.
- **Return:** Jakmile program narazí na `return`, funkce okamžitě končí.
- **Rekurze:** Je elegantní, ale náročná na paměť (každé volání zabírá místo na zásobníku).
- **Parametry:** Pokud chceš, aby funkce změnila hodnotu proměnné z `main()`, musíš použít pointery (volání odkazem).
