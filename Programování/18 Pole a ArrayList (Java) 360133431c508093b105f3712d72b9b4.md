# 18. Pole a ArrayList (Java)

---

### 1. Charakteristika polí v Javě

V Javě je pole vnímáno jako **objekt**. To je hlavní rozdíl oproti jazyku C.

- **Pevná velikost:** Velikost pole se určuje při jeho vytvoření a nelze ji později změnit.
- **Indexování:** Prvky jsou přístupné přes indexy `0` až `n-1`.
- **Atribut `.length`:** Každé pole v Javě ví, jak je velké. K jeho délce přistupujeme pomocí `pole.length`.
- **Kontrola mezí:** Java (na rozdíl od C) hlídá, zda nesaháte mimo pole. Pokud ano, program skončí chybou `ArrayIndexOutOfBoundsException`.

### 2. Jednorozměrné a vícerozměrné pole

### Jednorozměrné pole:

- **Deklarace:** `int[] cisla;`
- **Vytvoření:** `cisla = new int[5];` (v paměti se vytvoří místo pro 5 celých čísel a automaticky se vynulují).
- **Inicializace:** `int[] pole = {10, 20, 30};`

### Vícerozměrné pole:

- Nejčastěji 2D pole (matice), což je v Javě vlastně „pole polí“.
- **Deklarace:** `int[][] matice = new int[3][3];`
- Přístup k prvku: `matice[0][2] = 5;` (nultý řádek, druhý sloupec).

### 3. Třídění v poli

Pro řazení prvků v Javě nemusíte vždy psát vlastní algoritmus (jako Bubble Sort).

- Java nabízí pomocnou třídu `Arrays`.
- **Příkaz:** `Arrays.sort(pole);` – tento příkaz pole seřadí vzestupně.
- Pro použití je nutné na začátku souboru uvést `import java.util.Arrays;`.

### 4. Kolekce a ArrayList

**Kolekce** jsou v Javě pokročilé datové struktury (třídy), které slouží k ukládání a manipulaci s objekty. Na rozdíl od polí jsou dynamické.

### ArrayList:

Je to nejpoužívanější kolekce, kterou si lze představit jako **dynamické pole**.

- **Hlavní vlastnost:** Pokud se ArrayList zaplní, automaticky se nafoukne (přidá si místo pro další prvky).
- **Omezení:** Do ArrayListu lze ukládat pouze **objekty**, nikoliv primitivní typy (např. místo `int` musíme použít `Integer`).
- **Metody pro práci:**
    - `add(prvek)` – přidá prvek na konec.
    - `get(index)` – vrátí prvek na dané pozici.
    - `size()` – vrátí aktuální počet prvků (pozor, u pole je to `.length`).
    - `remove(index)` – smaže prvek a ostatní prvky "posune", aby nevznikla mezera.
    - `clear()` – vymaže celý seznam.

---

### Praktický příklad: Srovnání v kódu

Java

```java
import java.util.ArrayList;

public class Main {
    public static void main(String[] args) {
        // 1. Pole (pevné)
        int[] pole = new int[2];
        pole[0] = 10;
        pole[1] = 20;
        // pole[2] = 30; // CHYBA! Pole je plné.

        // 2. ArrayList (dynamický)
        ArrayList<Integer> seznam = new ArrayList<>();
        seznam.add(10);
        seznam.add(20);
        seznam.add(30); // V POŘÁDKU! ArrayList se zvětšil.

        System.out.println("Délka pole: " + pole.length);
        System.out.println("Velikost seznamu: " + seznam.size());
    }
}
```

---

### 💡 Tahák pro maturanta (klíčové body):

- **Pole:** Rychlé, pevná velikost, atribut `.length`.
- **ArrayList:** Flexibilní, dynamická velikost, metoda `.size()`.
- **Typy:** Do pole lze dát `int`, do ArrayListu musíme dát `Integer` (tzv. obalové třídy).
- **Metody ArrayListu:** Pamatuj si `add`, `get`, `remove`, `size`.
- **Kdy co použít?** Pole použij, když přesně víš, kolik dat bude (např. dny v týdnu). ArrayList použij, když se počet dat mění (např. seznam zákazníků v e-shopu).
