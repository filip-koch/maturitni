# 19. Znaky a řetězce (Java)

---

### 1. Znaková proměnná (`char`)

Základní typ pro uložení jednoho znaku.

- **Charakteristika:** V Javě zabírá `char` **2 bajty** (16 bitů).
- **Kódování:** Používá se **Unicode (UTF-16)**, což umožňuje reprezentovat znaky téměř všech světových abeced, nikoliv jen základní latinku jako v C.
- **Zápis:** Hodnoty se píší do jednoduchých apostrofů (např. `'A'`, `'@'`, `'\u0041'`).
- **Převody:** Znak lze snadno převést na celé číslo (pořadí v tabulce Unicode) a naopak.

### 2. Třída `String`

V Javě není řetězec polem, ale **instancí třídy `String`**.

- **Neměnnost (Immutability):** Toto je nejdůležitější vlastnost pro zkoušku. Jakmile je objekt `String` vytvořen, **nelze jej změnit**. Každá operace (např. spojení, změna písmene) ve skutečnosti vytvoří v paměti úplně nový objekt `String`.
- **Vytvoření:**
    - Literálem: `String s = "Ahoj";` (Využívá tzv. *String Pool* pro úsporu paměti).
    - Objektem: `String s = new String("Ahoj");` (Vytvoří vždy nový objekt v haldě).

### 3. Srovnávání řetězců (Častý chyták!)

U maturity musíte zdůraznit rozdíl mezi operátorem `==` a metodou `.equals()`:

- **`==`**: Porovnává **reference** (zda oba řetězce ukazují na stejné místo v paměti).
- **`.equals()`**: Porovnává **obsah** (zda jsou v řetězcích stejná písmena).
- *Pravidlo:* Pro text v Javě vždy používejte `.equals()`!

### 4. Nejdůležitější metody třídy `String`

Jelikož je `String` třída, nabízí mnoho vestavěných funkcí:

- **`length()`**: Vrátí počet znaků (pozor, u polí je to atribut `.length`, u Stringu je to metoda s závorkami).
- **`charAt(index)`**: Vrátí znak na dané pozici (indexuje se od 0).
- **`substring(od, do)`**: Vytáhne část řetězce.
- **`indexOf("text")`**: Najde pozici, kde se daný text vyskytuje.
- **`toUpperCase()` / `toLowerCase()`**: Změna velikosti písma.
- **`trim()`**: Odstraní bílé znaky (mezery) ze začátku a konce.
- **`split("oddělovač")`**: Rozseká řetězec na pole menších řetězců (např. větu na slova).

### 5. `StringBuilder` (Pro efektivní práci)

Pokud potřebujeme řetězec často měnit (např. v cyklu k němu tisíckrát něco přidat), je `String` nevýhodný, protože neustále vytváří nové objekty.

- Pro tyto účely existuje **`StringBuilder`**, který je měnitelný (mutable) a mnohem rychlejší při spojování textu pomocí metody `.append()`.

### Praktický příklad: Práce s textem v Javě

Java

```java
public class TextovyPriklad {
    public static void main(String[] args) {
        String jmeno = "  Jan Amos Komenský  ";
        
        // Úprava textu
        String upravene = jmeno.trim().toUpperCase();
        
        System.out.println("Původní délka: " + jmeno.length());
        System.out.println("Upraveno: [" + upravene + "]");
        
        // Srovnání
        String s1 = "Java";
        String s2 = new String("Java");
        
        System.out.println(s1 == s2);      // Vypíše false (různá místa v paměti)
        System.out.println(s1.equals(s2)); // Vypíše true (stejný text)
    }
}
```

### 💡 Tahák pro maturanta (klíčové body):

- **`char`** = 2 bajty, Unicode (víc než jen ASCII).
- **`String`** = Objekt, který je **neměnný** (immutable).
- **Porovnávání:** Vždy `.equals()`, nikdy `==`.
- **Metody:** Pamatuj si aspoň 4 (např. `length`, `charAt`, `substring`, `toLowerCase`).
- **Spojování:** Operátor `+` funguje (Java ho interně převede na StringBuilder), ale pro velké cykly je lepší přímo **`StringBuilder`**.
- **Indexy:** Stejně jako u pole začínají od 0.
