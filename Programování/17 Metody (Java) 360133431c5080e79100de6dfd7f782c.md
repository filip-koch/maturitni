# 17. Metody (Java)

---

### 1. Stavba a vlastnosti metody

Metoda je pojmenovaný blok kódu, který vykonává určitou činnost. V Javě nemůže metoda existovat „ve vzduchu“ – musí být vždy součástí nějaké třídy.

**Struktura (hlavička) metody:**`[modifikátor] [návratový_typ] [jméno_metody] (parametry) { ... tělo ... }`

- **Modifikátory přístupu:** Určují, kdo může metodu volat. Nejčastěji `public` (kdokoli) nebo `private` (pouze daná třída).
- **Návratový typ:** Typ dat, který metoda vrací (např. `int`, `String`, `boolean`). Pokud nic nevrací, používá se klíčové slovo **`void`**.
- **Jméno metody:** Podle konvence Javy začíná malým písmenem a používá tzv. *camelCase* (např. `vypocitejObsah`).
- **Parametry:** Seznam proměnných, které metoda přijímá. Musí mít definovaný typ a název.

### 2. Přetížení metod (Overloading)

V Javě můžeme mít ve stejné třídě více metod se **stejným jménem**, ale musí se lišit svou **signaturou**.

- **Signatura** se skládá ze jména a seznamu parametrů (jejich počtu nebo typu).
- Návratový typ se do signatury nepočítá – nemůžete mít dvě metody, které se liší jen tím, že jedna vrací `int` a druhá `double`.
- **Příklad:** Metoda `secti(int a, int b)` a metoda `secti(double a, double b)`. Java sama pozná, kterou zavolat, podle toho, jaká čísla jí předáte.

### 3. Statické metody (`static`)

Klíčové slovo `static` znamená, že metoda patří **třídě**, nikoliv konkrétnímu objektu (instanci).

- **Volání:** Statickou metodu voláme přímo přes jméno třídy (např. `Math.sqrt(16)`), nemusíme vytvářet objekt pomocí `new`.
- **Omezení:** Statická metoda nemůže přímo přistupovat k nestatickým (instančním) proměnným třídy, protože v době jejího volání nemusí žádný objekt existovat.
- **Příklad:** Metoda `main` je vždy statická, protože musí jít spustit jako první, dříve než vzniknou jakékoli objekty.

### 4. Předávání parametrů v Javě

U maturity je důležité zmínit, jak Java zachází s daty při volání metody:

1. **Primitivní typy (`int`, `double`, ...):** Předávají se **hodnotou**. Metoda dostane kopii a původní proměnnou nemůže změnit.
2. **Objekty a pole:** Předávají se **hodnotou odkazu**. Metoda dostane adresu objektu. To znamená, že metoda **může změnit vnitřní stav** objektu (např. změnit jméno psa), ale nemůže „přesměrovat“ původní proměnnou na úplně jiný objekt.

---

### Praktický příklad: Přetížení a statika

Java

```java
public class Kalkulacka {
    // Statická metoda - patří třídě
    public static void pozdrav() {
        System.out.println("Ahoj, jsem tvoje kalkulačka.");
    }

    // Přetížené metody pro sčítání
    public int secti(int a, int b) {
        return a + b;
    }

    public double secti(double a, double b) {
        return a + b;
    }
}
```

---

### 💡 Tahák pro maturanta (klíčové body):

- **Metoda** = funkce uvnitř třídy.
- **`void`** = metoda nic nevrací.
- **`return`** = ukončí metodu a vrátí výsledek (povinné, pokud typ není void).
- **Přetížení** = stejné jméno, jiné parametry (např. `println()` v Javě je přetížené pro všechny typy).
- **Statická metoda (`static`)** = patří třídě, volá se bez objektu (např. pomocné výpočty v `Math`).
- **`this`** = klíčové slovo odkazující na aktuální objekt (používá se v nestatických metodách pro rozlišení parametrů a atributů).
